# Reviewer guide: does this clause number bind the contract? (VETR reviewer gold)

You get evidence sheets: one block per clause number, with up to 3 quotes from the solicitation. The number is marked `>>>like this<<<`. For each block, answer one question: **if the contract is awarded as written, must the winner obey this clause (or answer this provision)?** Label:

- **B (binds):** the number is listed as incorporated by reference ("the following clauses are incorporated by reference", "Other Applicable Clauses"), its full text is printed in the document, its checkbox is marked (X, [X], checked box), or the text says it applies / is included in this contract.
- **N (does not bind):** the number is only mentioned — inside another clause's text ("as defined in 52.204-7"), in instructions or evaluation text, in a table of contents, in a header/footer, its checkbox is empty (`__`, `[ ]`, empty box), the text says it does not apply / is deleted, or it is not a real clause number (a fragment like "52.212" or a part number).
- **R (referenced requirement):** the narrative says the clause must be followed ("in accordance with FAR 52.204-7, registration is required", "refer to clause 52.211-12") without listing or incorporating it. Counts as *not binding* for the main score, *applicable* for the secondary score.
- **U (cannot decide):** the evidence does not let you decide (e.g. a lost checkbox marker with nothing else). Use sparingly and only when truly stuck.

Rules of thumb: a printed title next to the number does **not** mean it binds (unchecked checklist items print titles too). An unchecked box always beats a printed title. "Flow down" lists (roman numerals (i), (ii) inside subcontract clauses) do not bind the prime contract. When in doubt between N and R: R needs words like "shall comply", "in accordance with", "refer to" aimed at the contractor; otherwise N.

How to record: one line per item, `DOC.ITEM: LETTER`, e.g. `3.7: B`. A validator checks that every sampled item has exactly one of B/N/R/U. Take breaks; flag confusing documents rather than guessing (U with a note is better than a guess).

Time budget: about 30 seconds per number; the whole pack is about 25 reviewer-hours — split it.
